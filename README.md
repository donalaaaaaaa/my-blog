# my-blog

A calm, editorial personal blog rebuilt from the visual direction of XinghuisamaBlogs.

## Direction

- Editorial layout with generous whitespace
- Restrained blue-violet accent system
- Soft glass-like visual cards without over-decoration
- Responsive mobile-first layout
- Reduced-motion support and readable contrast

## Run locally

```bash
npm install
npm run dev
```

This first commit establishes the visual foundation. Content routes and the writing manager can be added on top of this shell.
